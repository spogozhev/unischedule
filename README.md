# Сводное расписание СПбГУ

[tt.apmath.info](https://tt.apmath.info)

Веб-приложение для составления сводного расписания на основе официального API [timetable.spbu.ru](https://timetable.spbu.ru). Позволяет объединить в одной таблице расписания нескольких учебных групп, аудиторий и преподавателей и сравнить их по дням недели и времени занятий.

## Возможности

- **Сводная таблица** — столбцы соответствуют учебной группе, аудитории или преподавателю, строки — дням недели и временным интервалам. Столбцы можно добавлять и удалять в любом количестве.
- **Поиск и добавление столбцов**:
  - *Группа* — быстрый поиск по локальному справочнику `groups.json` (например, `26.Б11-пу`) либо пошаговый выбор: подразделение → программа → год набора → группа;
  - *Аудитория* — поиск по адресу, затем по номеру кабинета;
  - *Преподаватель* — поиск по фамилии через API.
- **Выбор недели** — стрелки «назад/вперёд», кнопка «Сегодня» и календарь, в котором можно выбрать любую неделю (выделяются понедельники и текущая неделя).
- **Информация в ячейке** — дисциплина, время, группы, преподаватель, адрес и кабинет; отменённые занятия зачёркиваются, а несколько занятий в одном столбце с одинаковым временем выводятся вместе.

## Запуск

Приложение — статический сайт без сборки и npm-зависимостей. Достаточно запустить любой локальный HTTP-сервер из корня проекта (через `file://` браузер не сможет загрузить `groups.json`):

```bash
python -m http.server 8000
```

Затем открыть <http://localhost:8000>.

## Структура проекта

| Файл | Назначение |
|---|---|
| `index.html` | единственная страница приложения |
| `css/style.css` | стили в оформлении timetable.spbu.ru |
| `js/api.js` | обёртка `TimetableAPI` над REST API timetable.spbu.ru |
| `js/app.js` | логика приложения: состояние, рендеринг таблицы, поиск, выбор недели |
| `groups.json` | справочник всех учебных групп (~2 500 записей) для быстрого поиска |
| `scripts/export_groups.py` | скрипт выгрузки справочника групп из API в `groups.json` |

## Обновление справочника групп

`groups.json` генерируется скриптом, который обходит все подразделения СПбГУ (`/study/divisions` → программы каждого подразделения → группы каждой программы) и сохраняет записи вида `{id, name, division, program, level, year}`:

```bash
pip install requests
python scripts/export_groups.py
```

Обход занимает несколько минут (между подразделениями скрипт делает паузу в 1 секунду). 

## Используемое API

- Документация: <https://timetable.spbu.ru/help/ui/index>
- Swagger: <https://timetable.spbu.ru/docs/v1/swagger>
- Базовый адрес: `https://timetable.spbu.ru/api/v1`

Эндпоинты, используемые приложением:

| Endpoint | Назначение |
|---|---|
| `GET /study/divisions` | список подразделений |
| `GET /study/divisions/{alias}/programs/levels` | программы и годы набора подразделения |
| `GET /programs/{id}/groups` | учебные группы программы |
| `GET /groups/{id}/events/{from}/{to}` | занятия группы за период |
| `GET /addresses`, `GET /addresses/{oid}/classrooms` | адреса и аудитории |
| `GET /classrooms/{oid}/events/{from}/{to}` | занятия в аудитории за период |
| `GET /educators/search/{query}` | поиск преподавателей |
| `GET /educators/{id}/events/{from}/{to}` | занятия преподавателя за период |

Период для занятий групп и преподавателей передаётся датами в формате `YYYY-MM-DD`, для аудиторий — датой-временем в формате `YYYYMMDDHHmm` (с начала понедельника по конец воскресенья выбранной недели). Все запросы выполняются напрямую из браузера.
